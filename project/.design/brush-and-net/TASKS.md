# Build Tasks: Brush & Net POC

Single file `Brush & Net Prototype.dc.html`, iPhone frame, fictional data, EN/ES. Each task is a vertical slice that can be demoed on its own.

- [x] 1. **Shell + data**: iPhone frame, screen router, seeded route (14 stops incl. Fuel), pools, chems, prices, EN/ES string table, language state.
- [x] 2. **Today**: header, day card (earned, stops, progress, Shopping chip), next-stop hero, route order list (pool / non-pool / done variants), floating tab bar.
- [x] 3. **Log visit (core)**: timer, 4 reading steppers with Low/OK/High, prefilled chems with qty steppers + Changed state, task tiles, photo/note toggles, save bar with live earned.
- [x] 4. **Visit saved → Today**: net earned, breakdown, 3s countdown (Stay / Go now), return to Today with next hero; day card + done row update.
- [x] 5. **Add stop sheet**: Fuel / Supply store / Lunch, optional cost, inserted after current stop, cost flows to Money.
- [x] 6. **Shopping list**: grouped chems, totals, check items, Mark bought → cost added.
- [x] 7. **Pools + Pool detail**: search, rows with out-of-range flag, detail with margin, last readings, visit history.
- [x] 8. **Money**: Today / Week / Month, P&L (revenue, chems, other, net), costs list, shopping row.
- [x] 9. **Account**: business + fee, Language EN/ES, inactive "Coming soon" rows + sheet.
- [x] 10. **Onboarding (3 steps)**: language + business, fee stepper, first pools (Import row inactive) → Today.
- [x] 11. **Tweaks**: start screen, language, reset demo.
- [ ] 12. **Design review** against brief success test + a11y.
